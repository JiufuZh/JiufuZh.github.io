# Jiufu Zhou

An English portfolio focused on software engineering, applied AI, and two projects from a DeepBrain Technology internship.

**Live site:** [jiufuzh.github.io](https://jiufuzh.github.io/)

Updated October 21, 2026. Navigation selects **About, Chess, FOW or Research**, showing one view at a time. About introduces Jiufu's Informatics background, current UW studies, internship work and content-analysis experience. Project views use two columns on desktop: internship context and contributions beside the recording. On phones, the selected view stacks vertically.

## Run locally

No installation or build step is required. From this folder:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Open http://127.0.0.1:4173/ in a browser.

## Edit

- `index.html`: page content and structure.
- `styles.css`: responsive layout and presentation.
- `recordings.js`: clip chapters, screenshot paths, captions, playback timing and GIF links.
- `main.js`: shared screenshot player, clip switching and enlarged viewer.
- `nav.js`: exclusive content views, hash links, browser history and current-navigation state.
- `assets/`: portrait, favicon and approved project UI captures.
- [CONTENT.md](CONTENT.md): verified biographical and project facts.

Project summaries, large captures, plain chapter links and visible engineering notes keep the work easy to inspect. The Chess clip uses six actual local app screenshots: import, review, explanation, alternative, practice and solution. It runs bundled Stockfish with engine-backed coaching; no live LLM request was made during capture.

Fog of War has two local demonstrations:

- **Training run:** the project's original trainer executes on CPU with a tiny synthetic fixture. A new local event viewer displays observed training, checkpoint saving and resumption. It does not display invented progress or replay a historical full training run.
- **Browser integration:** the original userscript connects a newly built, permitted local test board to real FastAPI inference, using the checkpoint from the training demonstration. The model returns a move, which the script applies on the test board.

The approved internship dataset counts describe the original project data, not the small demonstration fixture. These clips demonstrate execution and integration, not playing strength or production deployment. The browser script is an integration userscript; it is not generated by an LLM.

The players and downloadable GIFs use actual execution snapshots with timing edited for readability, not continuous screen video. Each clip starts paused. Play/Pause retains the current frame and remaining time; Previous/Next and chapter links select individual snapshots. Playback ends at the final frame and can be replayed. Switching clips resets to the first frame. Changing views pauses players and closes the enlarged viewer. Playback also pauses when the document is hidden or an inline player leaves view; an enlarged clip can continue playing. Closing the viewer pauses it. Reduced-motion users can inspect every chapter manually. Keep demonstration captions in both inline and enlarged views.
