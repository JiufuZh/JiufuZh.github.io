Machine learning systems

Learning through the fog.

An AI agent that has to decide without seeing the whole board.

In Fog of War chess, an agent cannot see every opposing piece. I built the data and learning pipeline around what the player can actually observe, then connected model inference to a live game through a browser bridge.

Python / PyTorch / FastAPI / JavaScript

Dataset → Model training → Self-play → Inference and browser bridge. The pipeline uses 1,554 games and 88,949 plies, with player-visible observations and game-level splits.

↳

Respect the information boundary

Player-visible observations, masked opponent histories, and game-level splits help prevent hidden-information leakage.

↳

Connect learning to execution

Policy-and-value models connect training and self-play to a FastAPI service and JavaScript browser bridge.

↳

Check continuity

Checkpoint-resumption checks support repeatable training. Observation and move synchronization keep inference aligned with game state.

My scope: dataset preparation, model training, self-play, and inference integration.
